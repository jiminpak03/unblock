# Roles and Collaboration

A board's owner can invite other users to the board and assign each one a
role: VIEWER, EDITOR, or OWNER.

- VIEWER: can view the board's columns, cards, and dependency graph, but
  cannot make changes.
- EDITOR: can create and rename columns and categories, create and edit
  cards, move cards between columns, mark cards complete, and manage
  dependencies.
- OWNER: has all editor permissions, plus the ability to invite or remove
  members, change a member's role, and permanently delete the board.

Deleting a board permanently removes all of its columns, cards,
dependencies, and categories. This action cannot be undone.
