# Boards, Columns, and Cards

Editors and owners of a board can create and rename columns, and can create
cards inside a column. A card has a title, a description, and an optional
category. Categories are custom per board — each one has a name and a color,
so you can group cards by whatever fits your project (e.g. "Bug", "Feature",
"Design"). Cards are colored by their category so they're easy to tell apart
at a glance.

Cards can be moved between columns, edited, marked complete or incomplete,
or deleted by editors and owners. A card's completion status is independent
of which column it's in — you can mark a card complete without moving it.

Viewers can see a board's columns, cards, and dependency graph, but cannot
create, edit, move, or delete anything.
