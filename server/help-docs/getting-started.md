# Getting Started with Unblocked

Unblocked is a task board for tracking work and the dependencies between tasks.

To get started, sign up for an account or log in. Once logged in, you'll see
a list of the boards you're a member of. Click a board to open it, or create
a new board of your own — creating a board makes you its OWNER.

Every board has columns, cards, and a dependency graph. Columns represent
stages of work (like "To Do", "In Progress", "Done"). Cards represent
individual pieces of work and live inside a column.
