# Dependencies and the Dependency Graph

Editors and owners can mark that one card depends on another card, so the
team knows what's blocking what. A card cannot depend on itself.

The dependency graph is a board's default view. It shows every card as a
node and every dependency as an edge between two cards. Cards that are
currently unblocked (all of their dependencies are complete, or they have
none) are listed separately so you can quickly see what's available to
work on next.

Changes made by other members — card edits, status changes, new
dependencies — are reflected live on the board and the graph for everyone
viewing it, without needing to refresh the page.
